## Auto_Tools

반복적인 업무를 자동화하기 위해 만든 Windows 데스크탑 앱입니다.

- **평가 설정** — 전기→당기 종목 이전, 평가파일 종합 점검
- **보고서 관리** — 업무번호 삭제, Word→PDF 변환, 은행별 파일 분류, 보고서 검증
- **폴더 관리** — 폴더/파일 일괄 생성, 이름 변경
- **쿼리 관리** — SQL/TXT 파일 저장·편집·실행

**기술 스택**: Python 3.12, PyQt6, openpyxl, python-docx, pywin32
